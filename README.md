# MeowRa1n 🐾

> Jailbreak tool for iOS 17.4 – 26.2 Beta 1

## Supported
- **Devices**: A12 – A17 / M1 – M4
- **iOS**: 17.4 – 26.2 Beta 1

## Features
- Rootless (roothide) jailbreak
- Sileo package manager
- MeowSubstrate
- Auto re-jailbreak on reboot

## Build from source
```bash
# Install Theos first
git clone --recursive https://github.com/theos/theos.git /opt/theos
export THEOS=/opt/theos

# Build IPA
make package FINALPACKAGE=1
```
